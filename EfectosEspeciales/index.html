Aplicacion Propiedad
FLOAT

La propiedad float permite que un elemento se desplace hacia la izquierda o derecha dentro de su contenedor, permitiendo que otros elementos floten alrededor de él. (salen del flujo)

  • float: left; - El elemento flota a la izquierda del contenedor.
  • float: right; - El elemento flota a la derecha del contenedor.
  • float: none; - El elemento no flota y se comporta como un bloque normal.
CLEAR

La propiedad clear se utiliza para controlar el comportamiento de los elementos flotantes. Permite especificar si un elemento debe evitar flotar a su izquierda, derecha o ambos lados. (vuelve al flujo)

  • clear: left; - El elemento no permite que los elementos flotantes a su izquierda lo afecten.
  • clear: right; - El elemento no permite que los elementos flotantes a su derecha lo afecten.
  • clear: both; - El elemento no permite que los elementos flotantes a su izquierda ni a su derecha lo afecten.
  • clear: none; - El elemento no tiene restricciones sobre los elementos flotantes.

La propiedad overflow controla cómo se muestra el contenido que desborda el área de un elemento. Permite especificar si el contenido adicional se recorta, se muestra con barras de desplazamiento o se muestra automáticamente según sea necesario.

  • overflow: hidden; - El contenido que desborda el área del elemento se recorta y no se muestra.
  • overflow: scroll; - Se muestran barras de desplazamiento para permitir al usuario desplazarse por el contenido que desborda el área del elemento.
  • overflow: auto; - Se muestran barras de desplazamiento solo cuando el contenido desborda el área del elemento.
  • overflow: visible; - El contenido que desborda el área del elemento se muestra sin restricciones (valor predeterminado).
