flex-wrap: Permite que los elementos flexibles se envuelvan en múltiples líneas

 justify-content: Alinear los elementos en el contenedor flex horizontalmente
  • start: Alinea los elementos al inicio del contenedor
  • center: Alinea los elementos al centro del contenedor
  • end: Alinea los elementos al final del contenedor
  • space-around: Distribuye los elementos con espacio uniforme alrededor
  • space-between: Distribuye los elementos con espacio uniforme entre ellos
  • space-evenly: Distribuye los elementos con espacio uniforme entre ellos y alrededor

align-items: alinear los elementos en el contenedor flex verticalmente

  • flex-start: Alinea los elementos al inicio del contenedor
  • center: Alinea los elementos al centro del contenedor
  • flex-end: Alinea los elementos al final del contenedor
  • stretch: Estira los elementos para llenar el contenedor (por defecto)

align-content: Alinear los elementos en el contenedor flex verticalmente cuando hay múltiples líneas

  • flex-end: Alinea los elementos al final del contenedor
  • space-around: Distribuye los elementos con espacio uniforme alrededor

>flex-grow: Cuan de espacio extra se asigna a los elementos flexibles

flex-shrink: Cuanto puede encogerse un elemento flexible

  • 0: No se encoge (por defecto)
  • 1: Se encoge para llenar el espacio disponible
  • 2: Se encoge el doble que un elemento con flex-shrink: 1

order: Define el orden de los elementos flexibles dentro del contenedor

  • 0: El orden por defecto
