Display permite controlar cómo se muestra un elemento en la página

  • block: Hace que el elemento se muestre como un bloque de contenido (ocupa toda la línea)
  • inline: Muestra el elemento como un elemento en línea (ocupa solo el espacio necesario)
  • inline-block: Muestra el elemento como un bloque en línea (ocupa solo el espacio necesario pero se puede width y height)
  • none: Oculta el elemento
  • visibility:hidden : Hace que el elemento sea invisible pero ocupa espacio en la página

Position permite controlar la posición de un elemento en la página

  • static: Es el valor por defecto, el elemento se posiciona según el flujo normal del documento
  • relative: El elemento se posiciona en relación a su posición normal, permitiendo moverlo con las propiedades top, right, bottom y left
  • absolute: El elemento se posiciona en relación a su contenedor más cercano que tenga una posición diferente a static
  • fixed: El elemento se posiciona en relación al viewport, permaneciendo fijo incluso al hacer scroll
