Aplicacion Propiedad
Para hacer dar es "sass --watch styles.scss:styles.css"
VARIABLES

$background : red

.texto{

background : $background;

}

Se les llama con $
ANIDADCION Y &

.nav{

a{

color : red;

&:hover{

color : red;

}

}

}

El & se refiere al padre, en este caso a para agregarle un hover
PARTIALS

_header.scss

$color-fondo: red;

$color-letras: blue;

Los partials son archivos que se importan a otros archivos, puede contener variables, mixins, funciones, etc.
MIXINS

@mixin nombre-mixin($parametro){

propiedad : $parametro;

}

Los mixins son bloques de codigo que se pueden reutilizar, se les puede enviar parámetros
USOS DE @

@use 'header'; -> header.$variable

@ forward 'header';

@include nombre-mixin($parametro);

@extend .clase;

%placeholder{

propiedad : valor;

}
  • use : Permite importar partials
  • forward : Permite reexportar partials
  • include : Permite incluir mixins
  • extend : Permite extender estilos de otros selectores
  • %(placeholder) : Permite crear placeholders reutilizables
CALCULOS

.caja{

width : calc(100px / 2) ;

height : 100px + 50px;

background : red;

}

Sass permite realizar cálculos matemáticos para asignar valores a las propiedades, como sumar, restar, multiplicar o dividir unidades de medida. Si no se usa una misma medida se usa calc()
FUNCIONES

.caja{

background : color.adjust($color-fondo, $luminosidad: 20%);

}

Se aplica luminosidad

  • color.adjust (color, luminosidad) -> Permite ajustar la luminosidad de un color
  • color.mix (color1, color2, porcentaje) -> Permite combinar dos colores
