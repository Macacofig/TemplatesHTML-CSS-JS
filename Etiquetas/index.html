form -> Etiqueta para crear un formulario

  • action -> Atributo que especifica la URL a la que se enviarán los datos del formulario
  • method -> Atributo que especifica el método HTTP para enviar los datos del formulario (GET o POST)

  • label -> Etiqueta para definir una etiqueta para un elemento de formulario
  • input -> Etiqueta para crear un campo de entrada en el formulario
  • type -> Atributo que especifica el tipo de campo de entrada
    • text -> Campo de texto para ingresar texto
    • email -> Campo de texto para ingresar una dirección de correo electrónico
    • password -> Campo de texto para ingresar una contraseña
    • number -> Campo de texto para ingresar un número
    • checkbox -> Campo de selección que permite seleccionar una o más opciones
    • radio -> Campo de selección que permite seleccionar solo una opción
    • file -> Campo de entrada para seleccionar un archivo desde el dispositivo
  • name -> Atributo que especifica el nombre del campo de entrada
  • value -> Atributo que especifica el valor del campo de entrada
  • textarea -> Etiqueta para crear un área de texto en el formulario
  • button -> Etiqueta para crear un botón en el formulario funciona como input submit pero mejor
  • select -> Etiqueta para crear una caja de selección en el formulario
  • select option -> Etiqueta para crear una opción dentro de una caja de selección
SEMANTICAS

header -> Encabezado de la página

nav -> Barra de navegación

main -> Contenido principal de la página

section -> Sección del contenido

article -> Artículo o entrada de blog

aside -> Contenido relacionado o barra lateral

footer -> Pie de página

Las etiquetas semánticas ayudan a estructurar el contenido de una página web y mejorar su accesibilidad y SEO.
FIGURES

figure -> Etiqueta para agrupar contenido relacionado con una imagen o ilustración

figcaption -> Etiqueta para proporcionar un título o descripción a una figura

img -> Etiqueta para insertar una imagen en la página

  • src -> Atributo que especifica la URL de la imagen
  • alt -> Atributo que proporciona una descripción alternativa de la imagen para mejorar la accesibilidad

iframe -> Etiqueta para insertar una ventana independiente de otra pagina

  • src -> Atributo que especifica la URL de la página que se mostrará dentro del iframe
  • title -> Atributo que proporciona un título para el iframe
  • frameborder -> Atributo que especifica si se debe mostrar un borde alrededor del iframe (0 para no mostrar, 1 para mostrar)
  • allow -> Atributo que especifica las características permitidas dentro del iframe, como acelerómetro, autoplay, clipboard-write, encrypted-media, gyroscope, picture-in-picture y web-share
  • referrerpolicy -> Atributo que especifica la política de referencia para el iframe
  • allowfullscreen -> Atributo booleano que permite que el iframe se muestre en pantalla completa

video -> Etiqueta para insertar un video en la página

  • controls -> Atributo booleano que muestra los controles del video
  • width -> Atributo que especifica el ancho del video
  • height -> Atributo que especifica la altura del video

audio -> Etiqueta para insertar un audio en la página

  • controls -> Atributo booleano que muestra los controles del audio

video/audio source -> Etiqueta para especificar la fuente de un video

  • src -> Atributo que especifica la URL del video
  • type -> Atributo que especifica el tipo de video (por ejemplo, video/mp4)
